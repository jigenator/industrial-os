# Mission

A calm, truthful task dashboard as a real Herdr pane: see source health, what is
waiting, what is new, today's plan and the week's shipped work; triage directly
through the source collector's documented actions. Reuse the terminal design
system rather than shipping a browser mockup.

No account collection, private source configs, parallel data engine, agent rail,
portrait, tape, simulated telemetry, automatic live installation or new persistent
state. The engine owns authoritative snapshots and writes. The pane owns display,
input and bounded terminal lifecycle. Product interaction and visual decisions
stay with the maintainer; final fidelity acceptance is a taste decision.
