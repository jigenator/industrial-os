# Industrial OS

A native-terminal-first design system for precise, industrial interfaces. **Acid / Black** is the default: black fields, acid-green emphasis, clear white readouts, and restrained instrument-like detail.

This repository holds polished, reusable elements—not a collection of experiments.

## Status

The engineering standards and initial design direction are established. There are no released elements, runtime packages, or installation commands yet. The first delivery is a reference kit; implementation language and terminal framework remain undecided.
