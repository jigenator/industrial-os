# Contributing

Node 22, standard library, no build or project install. Run repository [setup](../CONTRIBUTING.md#setup) first for the exported design-system package. Follow [the guide](AGENTS.md). The chat and pictures need an installed Pi with a model logged in and its imagegen extension; no automated check uses them.

## Validation sequence

From repository root:

```sh
node --test lesson-maker/test/*.test.mjs
node lesson-maker/main.mjs --validate lesson-maker/examples/browser-caching.lesson.json
node lesson-maker/main.mjs --plain --size=180x48
node lesson-maker/main.mjs --plain --size=140x40
node lesson-maker/main.mjs --plain --size=100x24
node lesson-maker/main.mjs --plain --size=90x32
node lesson-maker/main.mjs --plain --size=80x30
node lesson-maker/main.mjs --plain --size=80x24
node lesson-maker/sample-image.mjs freshness > /tmp/lesson-maker-freshness.png
```

Equivalent project-local test command: `cd lesson-maker && node --test`. The isolated real-PTY test uses installed `python3` and its POSIX stdlib (`pty`, `termios`, subprocess), never live Herdr or external services; it edits copies of the example in a temporary folder and sets `LESSON_MAKER_PI` to a missing folder so no model is reached. AI requests are tested against `test/fake-ai.mjs` only.

A change to the Pi bridge, prompts or request flow also needs a real-Pi run, recorded separately: open a copy of the example (never the bundled file, which tests compare against), send a box request and a whole-lesson request, and generate one picture; check each lands in the file, which still validates, and that the picture records its prompt and model. Image generation uses the operator's imagegen login and quota. Tests fail rather than silently claiming PTY verification if that prerequisite is missing. Runtime app itself is Node-only.

Then run [repository-wide checks](../CONTRIBUTING.md#repository-wide-checks), including links/inventory/exact CLAUDE imports, whitespace and publication review. No root test command exists. No color values or other projects are changed.
